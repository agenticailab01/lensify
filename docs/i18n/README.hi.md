# ProjectLens

> किसी भी कोडबेस के लिए सिंगल-स्कैन एडैप्टिव प्रोजेक्ट लेंस + टोकन-ऑप्टिमाइज़्ड कॉन्टेक्स्ट कैप्सूल। AI कोडिंग एजेंट्स के लिए 70-90% ओरिएंटेशन टोकन बचाता है।

[English](../../README.md) · **हिन्दी** · [Português](README.pt.md) · [Русский](README.ru.md)

## यह क्या है

ProjectLens एक प्लगइन है जो **एक स्कैन** (50-150 ms) में किसी भी कोडबेस को बदलता है:

1. **`LENS.html`** — एक-पेज सारांश जिसे एक मनुष्य 30 सेकंड में पढ़ सकता है
2. **`LENS.capsule.md`** — 800-3,600 टोकन कॉन्टेक्स्ट ब्लॉक जिसे आपका AI एजेंट 30+ कच्ची फ़ाइलें पढ़ने के **बजाय** ग्रहण करता है
3. **30 फ्रेमवर्क एडाप्टर** 8 इकोसिस्टम पैक्स में (AI Apps, AI UIs, ML Core, Serving, Vector DB, Experiment, Enterprise, Notebooks)

## इंस्टॉलेशन

चार वितरण चैनल — अपने टूल से मेल खाने वाला चुनें:

```bash
# Claude Code / Cowork — projectlens.plugin को चैट में ड्रैग-एंड-ड्रॉप करें
# Cursor / VS Code Copilot / Codex / Gemini CLI — MCP सर्वर
git clone https://github.com/agenticailab01/projectlens ~/projectlens
# Aider / स्क्रिप्ट / CI — CLI
pip install projectlens
# कोई भी टूल जो कॉन्टेक्स्ट फ़ाइलें पढ़ता है — AGENTS.md मोड
projectlens . --install-agents-md
```

## मुख्य विशेषताएं

- **एडैप्टिव डेप्थ** — स्वचालित रूप से T1 (स्केच) / T2 (एटलस) / T3 (कम्पास) चुनता है
- **30 फ्रेमवर्क एडाप्टर** — PyTorch, Transformers, LangChain, Pinecone, FastAPI, SQLAlchemy, Vue SFC, Docker Compose और अधिक
- **5 सेशन हुक्स** (Claude Code) — रीड डिडुप, गतिविधि ट्रैकिंग, चयनात्मक इंजेक्शन, आउटपुट संपीड़न, क्रॉस-सेशन मेमोरी
- **कन्वर्सेशन कॉम्पैक्टर** — `/projectlens compact` के साथ सेशन के बीच में 8-25k टोकन पुनः प्राप्त करें
- **शुद्ध स्टैंडर्ड लाइब्रेरी** — शून्य रनटाइम निर्भरताएं
