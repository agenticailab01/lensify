# ProjectLens

> عدسة مشروع تكيفية بمسح واحد + كبسولة سياق محسّنة للرموز لأي قاعدة كود. توفر 70-90٪ من رموز التوجيه لوكلاء الترميز بالذكاء الاصطناعي.

[English](../../README.md) · [Русский](README.ru.md) · **العربية** · [Türkçe](README.tr.md)

## ما هو

ProjectLens هو إضافة تحوّل أي قاعدة كود في **مسح واحد** (50-150 مللي ثانية) إلى:

1. **`LENS.html`** — ملخص من صفحة واحدة يقرأه الإنسان في 30 ثانية
2. **`LENS.capsule.md`** — كتلة سياق من 800-3,600 رمز يستوعبها وكيل الذكاء الاصطناعي الخاص بك **بدلاً** من قراءة أكثر من 30 ملفًا
3. **30 محوّل إطار عمل** عبر 8 حزم نظام بيئي (AI Apps، AI UIs، ML Core، Serving، Vector DB، Experiment، Enterprise، Notebooks)

## التثبيت

أربع قنوات توزيع — اختر ما يناسب أداتك:

```bash
# Claude Code / Cowork — اسحب projectlens.plugin إلى الدردشة
# Cursor / VS Code Copilot / Codex / Gemini CLI — خادم MCP
git clone https://github.com/agenticailab01/projectlens ~/projectlens
# Aider / السكربتات / CI — CLI
pip install projectlens
# أي أداة تقرأ ملفات السياق — وضع AGENTS.md
projectlens . --install-agents-md
```

## الميزات الرئيسية

- **عمق تكيفي** — اختيار تلقائي T1 (رسم) / T2 (أطلس) / T3 (بوصلة)
- **30 محوّل إطار عمل** — PyTorch، Transformers، LangChain، Pinecone، FastAPI، SQLAlchemy، Vue SFC، Docker Compose والمزيد
- **5 خطافات جلسة** (Claude Code) — إلغاء تكرار القراءة، تتبع النشاط، الحقن الانتقائي، ضغط الإخراج، ذاكرة عبر الجلسات
- **مكثّف المحادثة** — `/projectlens compact` لاسترداد 8-25 ألف رمز في منتصف الجلسة
- **مكتبة قياسية نقية** — لا تبعيات لوقت التشغيل
