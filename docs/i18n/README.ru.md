# ProjectLens

> Адаптивная проектная линза одного сканирования + оптимизированная по токенам контекстная капсула для любой кодовой базы. Экономит 70-90% ориентационных токенов для AI-агентов кодирования.

[English](../../README.md) · **Русский** · [العربية](README.ar.md) · [Українська](README.uk.md)

## Что это

ProjectLens — плагин, который **одним сканированием** (50-150 мс) превращает любую кодовую базу в:

1. **`LENS.html`** — одностраничный обзор, который человек читает за 30 секунд
2. **`LENS.capsule.md`** — контекстный блок 800-3 600 токенов, который ваш AI-агент усваивает **вместо** чтения 30+ исходных файлов
3. **30 адаптеров фреймворков** в 8 экосистемных пакетах (AI Apps, AI UIs, ML Core, Serving, Vector DB, Experiment, Enterprise, Notebooks)

## Установка

Четыре канала распространения — выберите подходящий для вашего инструмента:

```bash
# Claude Code / Cowork — перетащите projectlens.plugin в чат
# Cursor / VS Code Copilot / Codex / Gemini CLI — MCP-сервер
git clone https://github.com/agenticailab01/projectlens ~/projectlens
# Aider / скрипты / CI — CLI
pip install projectlens
# Любой инструмент, читающий контекстные файлы — режим AGENTS.md
projectlens . --install-agents-md
```

## Ключевые возможности

- **Адаптивная глубина** — автоматический выбор T1 (Эскиз) / T2 (Атлас) / T3 (Компас)
- **30 адаптеров фреймворков** — PyTorch, Transformers, LangChain, Pinecone, FastAPI, SQLAlchemy, Vue SFC, Docker Compose и др.
- **5 хуков сессии** (Claude Code) — дедупликация чтения, отслеживание активности, селективное внедрение, сжатие вывода, межсессионная память
- **Компактор беседы** — `/projectlens compact` для возврата 8-25k токенов в середине сессии
- **Чистая стандартная библиотека** — ноль зависимостей среды выполнения

## Экономика токенов
