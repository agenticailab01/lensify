# ProjectLens

> Адаптивна проектна лінза з одноразовим скануванням + оптимізована за токенами капсула контексту для будь-якої кодової бази. Економить 70-90% орієнтаційних токенів для AI-агентів кодування.

[English](../../README.md) · [Türkçe](README.tr.md) · **Українська** · [Tiếng Việt](README.vi.md)

## Що це

ProjectLens — плагін, який **одним скануванням** (50-150 мс) перетворює будь-яку кодову базу на:

1. **`LENS.html`** — односторінкове резюме, яке людина читає за 30 секунд
2. **`LENS.capsule.md`** — блок контексту 800-3 600 токенів, який ваш AI-агент засвоює **замість** читання 30+ файлів
3. **30 адаптерів фреймворків** у 8 пакетах екосистеми (AI Apps, AI UIs, ML Core, Serving, Vector DB, Experiment, Enterprise, Notebooks)

## Встановлення

Чотири канали розповсюдження — оберіть відповідний вашому інструменту:

```bash
# Claude Code / Cowork — перетягніть projectlens.plugin у чат
# Cursor / VS Code Copilot / Codex / Gemini CLI — MCP-сервер
git clone https://github.com/agenticailab01/projectlens ~/projectlens
# Aider / скрипти / CI — CLI
pip install projectlens
# Будь-який інструмент, що читає контекстні файли — режим AGENTS.md
projectlens . --install-agents-md
```

## Ключові функції

- **Адаптивна глибина** — автоматичний вибір T1 (Ескіз) / T2 (Атлас) / T3 (Компас)
- **30 адаптерів фреймворків** — PyTorch, Transformers, LangChain, Pinecone, FastAPI, SQLAlchemy, Vue SFC, Docker Compose та інші
- **5 гачків сесії** (Claude Code) — дедуплікація читання, відстеження активності, селективне впровадження, стиснення виводу, міжсесійна пам'ять
- **Компактор розмови** — `/projectlens compact` для повернення 8-25k токенів у середині сесії
- **Чиста stdlib** — нуль залежностей виконання
